The bigger things on the list. There are no dates: this is a free app made by one person, and the order can change.

Android version

Planned

TCG Game Planner for Android phones and tablets, with the same decks, collection, sideboard plans and tournaments, and backups that open on either platform.

Windows version

Planned

A desktop version for Windows, with the same features as the Mac app and backups that open on every platform.
