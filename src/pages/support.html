Tickets are public.

Anyone can read what you post. Do not include your e-mail address, your backup files, API keys or service-account keys. Screenshots are welcome; crop out anything personal first.

What to include

  • Your device (for example iPhone 15, iPad Air, MacBook Air M2) and its iOS, iPadOS or macOS version.
  • The app version, from Settings › About.
  • What you did, step by step; what you expected; what happened instead.
  • A screenshot or screen recording, if it shows the problem.

You will need a GitHub account

Tickets live on GitHub Issues. Opening one needs a free GitHub account. Reading existing tickets does not, so search there first: your question may already have an answer.

What to expect

TCG Game Planner is a free app made by one person. Replies are on a best-effort basis. Bugs that lose data come first, then bugs that block a feature, then everything else. When a fix ships, the ticket says in which version, and the release notes list it.

Security issues

Please do not report a security problem in a public ticket. Use Report a vulnerability on the repository, which only the developer can see.
